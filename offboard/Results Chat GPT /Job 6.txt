## 1. What is the default value of `num_predict` when not set?

**QUOTED**

Ollama's current Modelfile reference states:

> "`num_predict` | Maximum number of tokens to predict when generating text. (Default: -1, infinite generation)" ([Ollama][2])

**Result:** default documented value = `-1`.

**NOT FOUND:** A checked source-code line showing the literal initialization of `NumPredict` in the current Ollama source.

---

## 2. Does `num_predict` count reasoning/thinking tokens, answer tokens, or both?

**QUOTED**

Ollama documents `num_predict` only as:

> "Maximum number of tokens to predict when generating text." ([Ollama][2])

Ollama's API documentation separately documents thinking output:

> "`think`: (for thinking models) should the model think before responding?" ([GitHub][1])

and:

> "The `message.thinking` ... field contains the reasoning trace while `message.content` ... holds the final answer." ([Ollama][3])

**NOT FOUND**

I did not find a checked Ollama source line that explicitly states whether `num_predict` counts:

* thinking tokens only,
* answer tokens only,
* or the sum of both.

**Status:** UNKNOWN.

---

## 3. When `num_predict` is reached, how does the request end? Is there a stop-reason field?

**QUOTED**

The Ollama API examples show completed responses containing:

> `"done": true` ([GitHub][1])

**NOT FOUND**

I did not find an official documentation page that lists the complete set of stop-reason values.

**UNVERIFIED**

A community report shows a response containing:

```json
"done_reason": "length",
"done": true
```

and attributes it to reaching a length limit. This is not an official Ollama source. ([Reddit][5])

**Status:** `done_reason` exists in at least one observed response, but official field/value documentation was NOT FOUND.

---

## 4. Is there a reasoning-specific budget / thinking length parameter?

**QUOTED**

Ollama has a `think` parameter:

> "Set the `think` field on chat or generate requests." ([Ollama][3])

For supported models:

> "Most models accept booleans (`true`/`false`). GPT-OSS instead expects one of `low`, `medium`, or `high` to tune the trace length." ([Ollama][3])

**Result:**

* A general Ollama reasoning budget parameter: **NOT FOUND**
* A `think` control exists.
* GPT-OSS has documented thinking levels (`low`, `medium`, `high`). ([Ollama][3])

**NOT FOUND**

The Ollama source/documentation checked did not identify a parameter named:

* `thinking_budget`
* `max_thinking_length`
* equivalent general reasoning token ceiling

---

**QUOTED**

**NOT FOUND in official documentation.**
