# 3. Ollama partial `options`: are Modelfile parameters retained?

## Answer: **YES**

**QUOTED**

Ollama API documentation:

> "`options`: additional model parameters listed in the documentation for the Modelfile such as `temperature`"   

Ollama Modelfile documentation:

> "`PARAMETER` instruction defines a parameter that can be set when Ollama will run the model."   

**INFERRED**

A request supplying only:

```json
{
  "options": {
    "temperature": 0
  }
}
```

overrides temperature only. Parameters not supplied remain from the model configuration.

Therefore:

## Plain answer: YES — `presence_penalty 1.5` remains active.
