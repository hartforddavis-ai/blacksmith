# JOB — RULE THREE CLAIMS ABOUT UNIT 7

## AIM

Check each claim below against the pasted source. Do not redesign the unit, do
not improve the claims, do not comment on the source.

No single line settles any of these claims. Each is settled by two lines read
together, or by none.

---

## PROCEDURE

```
FOR EACH claim:
    q = the pasted line or lines that settle it

    IF there is no such q                → UNSUPPORTED
    IF q contradicts the claim           → MISQUOTED. Give what the source says.
    IF q is present and supports it      → VERIFIED
```

---

## CLAIMS

```
C1  Under normal load the relay never closes.
C2  Under peak load the relay would open if it were closed.
C3  The unit draws more current when the status lamp is green than when it
    is dark.
```

---

## OUTPUT

Begin each row with the claim's identifier exactly as written above — `C1`,
`C2`, and so on. A row that does not name its claim cannot be read.

```
TOOLS HELD: <none, or name any you hold>

| Claim | VERIFIED / MISQUOTED / UNSUPPORTED | Evidence |

COUNTS
VERIFIED n · MISQUOTED n · UNSUPPORTED n
```

The Evidence cell must carry EVERY supporting line in double quotes, copied
from the source exactly, one quoted span per line relied on. A row with no
quoted span is not a positive verdict.
